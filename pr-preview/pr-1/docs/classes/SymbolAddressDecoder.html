Class SymbolAddressDecoder

Nearest-symbol decoder. The first ELF whose executable range contains the address wins. An application hit also takes its file and line from that ELF's line table. The ROM ELF is last and is labeled ROM with no line. A 9-character tail is held back while a fragment is unfinished so an address split across reads is not decoded twice.
