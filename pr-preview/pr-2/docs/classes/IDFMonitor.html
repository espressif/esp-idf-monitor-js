Class IDFMonitor

Serial console for an ESP-IDF target.

The page supplies an already granted port and a terminal. Chip text is written to the terminal. Ctrl+T menu commands, panic and core-dump capture, and address decoration stay inside this object and are reported with IDFMonitor.on.
